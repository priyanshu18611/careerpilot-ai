# 🚀 CareerPilot AI

> AI-powered career platform for resume analysis, ATS optimization, job matching and interview preparation.

## 🌟 About

CareerPilot AI is an intelligent career platform designed to help students, freshers and professionals improve their resumes, understand ATS compatibility and make better career decisions.

## ✨ Features

- 📄 AI Resume Analyzer
- 🎯 ATS Resume Score
- 🔍 Skill Extraction
- 💼 Job Matching
- 🤖 AI Career Coach
- 🎤 Interview Preparation
- 📊 Career Dashboard
- 📈 Resume Improvement Suggestions
- 🔐 Secure User Authentication
- ⚡ REST API
