# Contributing to CareerPilot AI

Thank you for your interest in contributing to CareerPilot AI.

CareerPilot AI is an AI-powered career intelligence platform focused on resume analysis, ATS optimization and career guidance.

## Getting Started

1. Fork the repository.
2. Clone your fork locally.
3. Create a new branch for your changes.
4. Install the backend dependencies.
5. Make your changes.
6. Run the available tests.
7. Commit your changes.
8. Push your branch.
9. Open a Pull Request.
